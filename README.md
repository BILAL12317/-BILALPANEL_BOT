# BILAL PANEL SHOP BOT

Professional Telegram Bot built with Python.

## Features

- 🛒 Buy Panel
- 💰 Price List
- 💳 UPI Payment
- 📦 Order System
- 👤 User Management
- 📢 Broadcast
- 🔔 Admin Notifications
- 🔥 Firebase Database
- ☁️ Koyeb Ready

## Requirements

- Python 3.11+
- python-telegram-bot
- firebase-admin
- python-dotenv

## Setup

1. Clone this repository.
2. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Create a `.env` file from `.env.example`.
4. Add your Bot Token.
5. Add your Firebase service account key.
6. Run:
   ```bash
   python main.py
   ```
